## 3. Теоретическая часть

### 3.1. Компенсация движения

**Компенсация движения (motion compensation)** — технология, используемая в видеокодеках для повышения сжатия. Вместо хранения каждого кадра отдельно, кодируется только разница между кадрами на основе оценки движения объектов.

#### 3.1.1. Базовые принципы

- **Внутрикадровое кодирование (I-frames):** кадр хранится как полный кадр
- **Межкадровое кодирование (P-frames):** хранятся векторы движения и остатки
- **Двунаправленное кодирование (B-frames):** используют кадры до и после для сжатия

### 3.2. Метод поиска блоков (Block Matching)

**Метод поиска блоков** — один из основных алгоритмов оценки движения в видеокодеках.

#### 3.2.1. Принцип работы

Изображение делится на блоки (обычно 16×16 пикселей). Для каждого блока в текущем кадре находится наиболее похожий блок в предыдущем или следующем кадре. Разность координат определяет вектор движения.

#### 3.2.2. Метрики сходства

- **SAD (Sum of Absolute Differences):** сумма абсолютных разностей значений пикселей
- **SSD (Sum of Squared Differences):** сумма квадратов разностей
- **NCC (Normalized Cross-Correlation):** нормализованная перекрёстная корреляция

**Формула SAD:**

```
SAD = Σ|f(x,y) - g(x+dx, y+dy)|
```

**Формула SSD:**

```
SSD = Σ(f(x,y) - g(x+dx, y+dy))²
```

**Формула NCC:**

```
NCC = (Σ(f(x,y)·g(x+dx, y+dy)) - μf·μg·N) / (σf·σg·N)
```

где:

- f — текущий кадр
- g — предыдущий кадр
- (dx, dy) — вектор движения
- μf, μg — средние значения яркости
- σf, σg — стандартные отклонения
- N — количество пикселей в блоке

### 3.3. Оптический поток

**Оптический поток (optical flow)** — метод оценки движения на основе анализа изменений яркости пикселей между кадрами.

#### 3.3.1. Метод Фарнебака

OpenCV реализует алгоритм Фарнебака для плотного оптического потока:

```python
flow = cv2.calcOpticalFlowFarneback(
    prev_gray, next_gray, None,
    0.5, 3, 15, 3, 5, 1.2, 0
)
```

**Параметры:**

- `pyr_scale` (0.5) — масштаб пирамиды
- `levels` (3) — количество уровней пирамиды
- `winsize` (15) — размер окна поиска
- `iterations` (3) — итерации на каждом уровне
- `win_size_pyr_range` (5) — размер окна на следующем уровне пирамиды
- `polynomial_steps` (1.2) — количество полиномиальных шагов
- `flags` (0) — флаги алгоритма

```python
def visualize_motion_vectors(img, flow):
    """Наносит векторы движения на изображение."""
    h, w = img.shape[:2]
    
    # Создаём копию изображения для отрисовки
    result = img.copy()
    
    # Рисуем стрелки для каждого пикселя (или подмножества)
    for y in range(0, h, 8):
        for x in range(0, w, 8):
            dx = flow[y, x, 0]
            dy = flow[y, x, 1]
            
            # Пропускаем нулевые векторы
            if abs(dx) < 0.1 and abs(dy) < 0.1:
                continue
            
            # Рисуем стрелку
            cv2.arrowedLine(result, (x, y), (int(x + dx), int(y + dy)), (0, 255, 0), 1)
    
    return result
```

```python
    """Оценивает движение блоков между кадрами."""
```

#### 3.5.2. Сравнение методов оценки движения

```python
def compute_sad(block1, block2):
    """Вычисляет SAD (Sum of Absolute Differences)."""
    return np.sum(np.abs(block1.astype(float) - block2.astype(float)))


def compute_ssd(block1, block2):
    """Вычисляет SSD (Sum of Squared Differences)."""
    diff = block1.astype(float) - block2.astype(float)
    return np.sum(diff ** 2)


def compute_ncc(block1, block2):
    """Вычисляет NCC (Normalized Cross-Correlation)."""
    b1_mean = np.mean(block1)
    b2_mean = np.mean(block2)
    b1_std = np.std(block1)
    b2_std = np.std(block2)
    
    if b1_std == 0 or b2_std == 0:
        return 0
    
    ncc = np.sum((block1 - b1_mean) * (block2 - b2_mean)) / (b1_std * b2_std * block1.size)
    return ncc


def compare_motion_estimation_methods(video_path):
    """Сравнивает методы оценки движения."""
    cap = cv2.VideoCapture(video_path)
    
    ret, prev_frame = cap.read()
    prev_gray = cv2.cvtColor(prev_frame, cv2.COLOR_BGR2GRAY)
    
    results = {
        'block_matching': [],
        'optical_flow': []
    }
    
    while True:
        ret, curr_frame = cap.read()
        if not ret:
            break
        
        curr_gray = cv2.cvtColor(curr_frame, cv2.COLOR_BGR2GRAY)
        
        # Метод поиска блоков
        block_vectors = estimate_block_motion(prev_gray, curr_gray)
        results['block_matching'].append(block_vectors)
        
        # Оптический поток Фарнебака
        flow = cv2.calcOpticalFlowFarneback(
            prev_gray, curr_gray, None,
            0.5, 3, 15, 3, 5, 1.2, 0
        )
        results['optical_flow'].append(flow)
        
        prev_gray = curr_gray
    
    cap.release()
    return results
```

### 3.6. Анализ вычислительной сложности

#### Метод поиска блоков

- **Сложность:** O(W·H·S²) где W, H — размеры кадра, S — размер области поиска
- Для кадра 1920×1080 с блоками 16×16 и областью поиска 32×32: ~4000 блоков × 1024 позиции = 4,096,000 операций

#### Оптический поток Фарнебака

- **Сложность:** O(W·H·L) где L — количество уровней пирамиды
- Быстрее метода поиска блоков для плотной оценки движения
